## Scope of this dataset

This dataset uses the historical Kowalik reference sequence ([AY421767.1](https://www.ncbi.nlm.nih.gov/nuccore/AY421767)), which may differ from contemporary global CVA10 strains. It is intended for broad subgenogroup classification, mutation quality control, and phylogenetic analysis of CVA10 diversity.

## Features

This dataset supports:

- Assignment of subgenotypes
- Phylogenetic placement
- Sequence quality control (QC)

## Subgenogroups of Cocksackievirus A10

The subgenogroups A-G represent major phylogenetic divisions within CVA10, commonly used in virological surveillance and literature. These are defined by phylogenetic clustering and do not necessarily indicate antigenic differences.

No standardized global lineage system is currently maintained, so subgenogroup naming follows historical and regional convention.
